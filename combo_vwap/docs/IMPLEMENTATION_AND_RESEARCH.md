## 2. 文献支持什么

1. **Kato, VWAP Execution as an Optimal Strategy (2015；长版本 2017)**。[论文原文](https://arxiv.org/abs/1408.6118)。在显式交易量及冲击模型、特定风险偏好假设下论证成交量驱动的执行；指出事前未知全天总量的问题。该论文的部分最优静态曲线涉及调和均值，因此本实现的“每日归一化后等权平均”不能称为对其最优公式的精确复现。
2. **Busseti & Boyd, Volume Weighted Average Price Optimal Execution (2015)**。[作者主页](https://web.stanford.edu/~boyd/papers/vwap_opt_exec.html)。同时考虑 VWAP 偏差、交易成本和总成交量不确定性，研究使用盘中新信息动态更新；其美股数据模拟中动态相对静态方案的跟踪 RMSE 改善约 10%。这不是相对 TWAP 的收益提升，更不是本实现的验证结果。
3. **Frei & Westray, Optimal Execution of a VWAP Order: a Stochastic Control Approach, Mathematical Finance 25 (2015), 612–639**。[作者提供的论文](https://www.math.ualberta.ca/~cfrei/CFNW2015.pdf)。对 VWAP 偏差的均值/方差与暂时冲击联合建模，说明跟踪 benchmark 与交易成本应一起考虑。

本实现借鉴“历史量曲线 + 盘中新量 + 成本/完成约束”的框架，采用可解释、可离线验证的工程近似，**没有求解上述论文的 HJB/LQ 最优控制问题**。参数 20 日、10 日下限、5 分钟刷新、60 分钟先验、15 个百分点偏差边界是工程默认，未用策略收益进行调参或声称最优。

## 3. 静态历史曲线

对股票 i 的每个历史交易日 d 和窗口分钟 t：

```
w[d,t] = volume[d,t] / sum_t(volume[d,t])
w[t]   = mean_d(w[d,t])
H[t]   = cumulative_sum(w[t]) * median_d(window_total[d])
F_static[t] = H[t] / H[T]
```

只读交易日之前 90 个自然日内的本地 1m 数据，从中取最近 20 个有效日，至少 10 日。最新有效日距交易日超过 14 个自然日则阻止执行，避免使用过期曲线。

09:30 开盘集合竞价、午休、收盘竞价不进入连续交易窗口曲线。使用 09:31–11:30、13:01–结束时间的收盘标记分钟。每个历史日窗口至少 95% 的分钟存在，并要求末分钟存在、首分钟不晚于开始后 5 分钟；少量缺分钟只在该历史样本内记零，绝不价格/成交量前向填充。重复时间、负量、NaN/Inf 则拒绝该历史日；全零日也拒绝。

这是一项明确的数据质量约定：极不活跃或行情缺失严重的股票可能被拦截，需要补数据和核实，不能当作“全天无量”继续执行。

## 4. 动态修正

在确定的 5 分钟网格上，使用已完成且连续完整的当日数据前缀。令 k 是已知前缀末端，A[k] 是实际累计量，H[k] 为预期累计量，T 是窗口终点：

```
prior = H[T] * 60 / window_minutes
scale = clip((A[k] + prior) / (H[k] + prior), 0.25, 4.0)
F_dynamic[t] = (A[k] + scale * (H[t] - H[k]))
               / (A[k] + scale * (H[T] - H[k]))
```

结果限制在静态进度 ±0.15 以内，并对历史已知各时点的目标取累计最大值，避免预测调整使目标进度后退；到窗口结束目标为 1。动态数据只使用截至 `min(bar_time, wall_time)` 前一整分钟，再向下对齐 5 分钟。

适配器再过滤一次日期和截止时间，防止数据接口忽略 `end_time` 引入前视。盘中必须有完整分钟前缀才进行相应动态更新；不完整/失败时沿用静态 VWAP 和已达到的进度下限，并打印状态。

正常历史与当日数据不被供应商回改时，重启重建使用相同前缀，得到相同进度。行情回改、运行中改窗口/参数不属于严格相同输入；此时原订单/成交对账仍约束剩余量，但不能宣称目标曲线完全相同。

这是对成交量**规模**进行自适应更新，尚未预测事件导致的未来成交量形状变化，也没有日内价格 alpha 模型。

## 5. 与原执行层连接

```
卖出累计目标 = 当日可执行总股数 * F_i(t)
新卖出量 = 累计目标 - 已卖 - 挂单 - 未确认订单

买入累计目标 = 按每名预算/当前价格计算的股数目标 * F_i(t)
新买入量 = 累计目标 - max(当前策略持仓+挂单, 已发出量, 今日已成交量)
```

之后沿用整手/科创板/北交所最小委托规则、分钟参与量上限、挂单方式和原恢复逻辑。买入预算仍会随价格换算成不同股数；没有将资金预算机制改成固定股数。

历史曲线无效时返回 `None`，买卖及补零头、竞价分支都检查此值，不会先整天阻止交易、最后突然无条件扫完。有效历史下的盘中数据失败只降级为静态 VWAP，不丢失原执行保护。

原框架的 QUEUE 未成交、涨跌停、停牌、拒单等仍可能导致无法完成，收尾不是成交保证。持仓与订单状态异常的原有处理继承自 TWAP，新增调度测试不等于重新证明每一项柜台行为。
